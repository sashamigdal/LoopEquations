# Decaying-turbulence structure function: thimbles, Stokes terms and wind-tunnel data

Code and results for

> A. Migdal, *Comparing the Decaying Turbulence Theory with Wind Tunnel Experiments* (2026), arXiv preprint.

These files are distributed with the arXiv paper as ancillary files (`anc/`), and they are kept in the folder
[`Mellin`](https://github.com/sashamigdal/LoopEquations/tree/master/Mellin) of the GitHub repository
`sashamigdal/LoopEquations`. The two copies have the same layout, and all paths below are relative to that folder.

Version v2.0 of this folder (arXiv v2) is archived on Zenodo: [doi:10.5281/zenodo.23068087](https://doi.org/10.5281/zenodo.23068087)
(v1.0, arXiv v1: [doi:10.5281/zenodo.23046503](https://doi.org/10.5281/zenodo.23046503)).

The code evaluates the Mellin–Barnes integrals of the odd Euler ensemble

```
G(ρ) = (1/2πi) ∫ ρ^q Z(q) dq,            −1 < Re q < 0      (velocity correlation)
D(ρ) = (1/2πi) ∫ ρ^q (−2 Z(q)) dq,        0 < Re q < 2      (structure function, D = 2(G(0) − G(ρ)))
Z(q) = −64√2 π csc(πq/2) f(−1−q) ζ(13/2−q) / ((128√2 − 2^q)(1+q)(2q−15)(2q−5) ζ(15/2−q))
α(ρ) = d log D / d log ρ
```

It uses steepest descent: saddle points, Lefschetz thimbles q(t) with log-weight W₀ − t², Gauss–Hermite quadrature along q(t),
and the Stokes terms (residues of the Riemann-wall poles 7 + iγₙ and dyadic-wall poles 15/2 + 2πim/log 2 trapped by the
thimble, and the tails of thimbles that end on the zeros 6 + iγₙ). It adds the finite-width correction and compares with
the Max Planck wind-tunnel data. In the code, `xi` = log ρ, and `r` means ρ unless it is marked as a physical length (r/η, metres).

## Requirements

Python ≥ 3.10 with `numpy`, `scipy`, `mpmath`, `matplotlib` (`pip install -r python/requirements.txt`). The pipeline was run
with Python 3.11, numpy 2.4, scipy 1.17, mpmath 1.3 and matplotlib 3.11. `scan.py` and `direct_D.py` use 4 processes.

## Reproducing the paper

```
cd python
bash run_all.sh                         # theory only: about 30 min on 4 cores
MPI_DATA_DIR=/path/to/E_Kohler bash run_all.sh   # also the wind-tunnel analysis of Sec. III
bash run_all.sh --readme                # also the README figures and side checks
```

Intermediate arrays go to `python/cache/` (not committed). Tables go to `results/`, and the figures of the paper go to
`paper/figs/` (`python paper_figures.py DIR` writes them elsewhere).

**The Max Planck data are not included.** They are the measurements of C. Küchler, G. P. Bewley and E. Bodenschatz,
Phys. Rev. Lett. **131**, 024001 (2023): 11 files `Re_<Re_λ>_Eps_<ε>.csv` with columns index, r/η, S₂ (m²/s²), S₃. They were
provided by the authors on request and are available from them. Without these files, `run_all.sh` skips the fits of
Sec. III and figures 8 and 9. The committed tables in `results/` hold the fitted parameters and the extrapolated index
α_∞ with its errors, but not the per-run measurements.

## The Mathematica package

`MellinOscillationsThimbles.wl` is a transcription of the Python algorithm. It was not used to produce the results of the
paper. To run it, put the `.wl` and `.nb` files, `results/pythonReference_D.csv` and (optionally) `E_Kohler/` in one folder
and evaluate `MellinOscillationsThimbles.nb`.

`ABCInterpolator.wl` reads `iqinterp.mx`, an interpolation of IQ(Δ). The `.mx` format depends on the platform, so it is not
distributed. To create it, uncomment the three lines `qtab = …; iqinterp = …; DumpSave[…]` in `ABCInterpolator.wl` and run it once.
The Python port rebuilt IQ from its definition rather than from `iqinterp.mx`, so the two agree to about 10⁻⁴ (for example
`DF[-3,0]` = 24062.6 against 24057.0). Inside *Mathematica* the real test is `ComputeMellin` against `DirectLine`.

## Notes on the computation

### Corrections to the first version of `MellinOscillationsOdd.nb`

1. `S1Interp[q] = df1approx[q] + S1Analytic[q]` must be `−df1approx[q] + S1Analytic[q]`, because d/dq log DF(−1−q) = −DF1/DF0.
2. `S2R` must be `+DF[−1−q,2]/DF[−1−q,0] − (DF1/DF0)² + S2Analytic`, not `−DF2/DF0 …`. The old value S2R(−0.5) = −7.40 makes
   v₀ real, so the "thimble" ran along the real axis until S1Interp + ξ = 0; this is where the `Infinite expression` messages
   came from. The correct value is S″(−0.5) = +9.0652.
3. `p0Values` contains q₀ = 0, which is a pole of csc.
4. The walls in q: Riemann poles at 7 ± iγₙ, dyadic poles at 15/2 ± 2πik/log 2, zeros at 6 ± iγₙ; q = 15/2 is a double pole.
5. The thimbles bend to the right, so trapping uses a rightward ray and the residues enter with a minus sign:
   F = F_thimble − 2 Re Σ Res.
6. Outside the [−1,0]×[0,10] grid the DF interpolation was not the log of DF. DF is now evaluated exactly on a fixed
   Gauss–Legendre grid in Δ (this is only the inner Δ-integral; the thimble integral is Gauss–Hermite).

### Results in brief

* **Three regimes of the thimble** for D. For log ρ > −2.87 the thimble bends left and traps nothing. For
  −3.8037 < log ρ ≤ −2.95 it ends on a zero 6 + iγₙ, with n = 1, 2, 3, 5, 6, 7, 8, 14 as log ρ → −2.87 (a zero-parking staircase).
  At log ρ₁ = −3.8037133 it passes a secondary saddle and escapes to the right, trapping all Riemann poles and the dyadic poles
  m ≥ 2 at once; the first dyadic pole follows at log ρ₂ = −4.2023635. In the spectrum the first event, at log κ = 5.3613093,
  traps eleven poles at once; the next ones come one to three at a time.
* **Oscillations.** For ρ > C_max = e^−2.76, D is a convergent series in real powers of 1/ρ: no oscillations. For
  ρ < C_min = e^−2.92 the only oscillating terms are the wall poles ρ^{7+iγₙ} and ρ^{15/2+2πik/log 2}. The dyadic k = 1 term
  dominates, with period log 2 in log ρ. In the residue representation the full wall sum is 1.4·10⁻⁶ of α at log ρ = −3; in the
  thimble representation only the trapped poles enter, Berry-smoothed: at most 7·10⁻⁹ in α, against 4.5·10⁻⁴ in the spectral index.
* **The large-r oscillations in `CorrelationOscillation.nb` come from the cutoff.** `Dv2` integrates `htab` only over
  0.1 < k < 1000, and H(0.1) = 0.037 is not small. The endpoint leaves a term ∝ H(0.1) cos(0.1 r)/r², so the index turns negative
  and oscillates for log₁₀ r > 1.4. `htab` agrees with this model's H(κ) to 0.3%.
* **Finite width.** The cutoff κ > κ_min = πℓ_D/W stands for the width W of the tunnel. H(κ) is entire, so the subtraction is
  exact. α_W oscillates about 0 with period 2π/κ_min in ρ (periodic, not log-periodic), and the first dip is near ρ ≈ W/ℓ_D.
  Fitted per run, it reproduces the dips of the measured index at the largest r. A single W = 2.34 m describes the
  Re_λ ≤ 2398 runs (rms 0.023 against 0.035 without it). The runs with Re_λ ≥ 3070 show no dip.
* **Boundary effects.** A separation longer than the width, r > W, cannot probe isotropic turbulence. These points (0–19% of
  each tail, where the dips are) are used only to find W and are left out of the Re_λ → ∞ comparison and of the attractor test.
  The flow as a whole is never in the regime L(t) ≳ W: the integral scale is L ≤ 0.18 W in every run.
* **Re_λ → ∞.** At fixed x = log(r/L), α(x, Re_λ) = α_∞(x) + c(x)/Re_λ (points r ≤ W only), and α_D(x − s) is fitted to α_∞
  with weights 1/σ²:

| runs used | s = log(ℓ_D/L) | ℓ_D/L | χ²/dof | weighted rms of α |
|---|---|---|---|---|
| all 11 (Re_λ ≥ 413) | 2.072 ± 0.030 | 7.94 | 4.3 | 0.022 |
| Re_λ ≥ 1046 (adopted) | 1.953 ± 0.017 | 7.05 | 1.6 | 0.013 |
| Re_λ ≥ 1305 | 1.937 ± 0.020 | 6.94 | 1.2 | 0.014 |
| Re_λ ≥ 2033 | 1.844 ± 0.012 | 6.32 | 1.3 | 0.012 |
| Re_λ ≥ 2398 | 1.811 ± 0.015 | 6.12 | 1.4 | 0.016 |

  The infinite-Re theory describes the extrapolated tail within its errors; no finite-width term is needed there. The ratio
  ℓ_D/L drifts from 7.9 to 6.1 as the lower-Re runs are dropped, more than the statistical errors, so part of the Re
  dependence is not captured by the 1/Re_λ term. An extrapolation in Re_λ^{−1/2} fits worse (χ²/dof 3.4, `extrapolate_Re.py`).
