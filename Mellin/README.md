# MellinOscillationsOdd — thimbles, Gauss–Hermite and Stokes corrections

This folder finishes the steepest-descent computation started in `MellinOscillationsOdd.nb`. It computes the correlation function
f(r), the structure function D(r) = 2(f(0) − f(r)) and the effective index α(log r) = r ∂_r log F. The method is the one from
`MellinOdd.nb`: saddle points, Lefschetz thimbles p(t) with log-weight S0 − t², Gauss–Hermite quadrature along
p(t), and residues of poles trapped between the vertical contour and the thimble (the Stokes phenomenon).

```
f(r) = (1/2πi) ∫ r^q ZR(q) dq,            −1 < Re q < 0
D(r) = (1/2πi) ∫ r^q (−2 ZR(q)) dq,        0 < Re q < 2
ZR(q) = −64√2 π Csc(πq/2) DF(−1−q) ζ(13/2−q) / ((128√2 − 2^q)(1+q)(2q−15)(2q−5) ζ(15/2−q))
```

## Bugs found in the revised part of `MellinOscillationsOdd.nb`

1. `S1Interp[q] = df1approx[q] + S1Analytic[q]` must be `−df1approx[q] + S1Analytic[q]`, because d/dq log DF(−1−q) = −DF1/DF0.
2. `S2R` must be `+DF[−1−q,2]/DF[−1−q,0] − (DF1/DF0)² + S2Analytic`, not `−DF2/DF0 …`. The old value S2R(−0.5) = −7.40 makes
   v0 real, so the "thimble" ran along the real axis until S1Interp + ξ = 0. That is where the `Infinite expression` messages came from.
   The correct value is S''(−0.5) = +9.0652.
3. `p0Values` contains q0 = 0, which is a pole of Csc.
4. The walls in q: Riemann poles are at 7 ± iγₙ (not 9 or −8), dyadic poles at 15/2 ± 2πik/ln 2 (not −17/2), and zeros at 6 ± iγₙ.
   q = 15/2 is a double pole.
5. The thimbles now bend to the right, so trapping uses a rightward ray and the residues enter with a minus sign:
   F = F_thimble − 2 Re Σ Res.
6. Outside the [−1,0]×[0,10] grid the DF interpolation was not the log of DF: it kept only Re log DF, fell back to a constant
   df1Mean, and used a linear-model fit for log|DF|. DF is now evaluated exactly on a fixed Gauss–Legendre grid in Δ. This is only
   the inner Δ-integral; the thimble integral is Gauss–Hermite.

## Results

* **Validation.** Thimble + Gauss–Hermite (80 nodes) + Stokes terms reproduce the direct vertical-line integral over
  log r ∈ [−8, 8] to 5·10⁻¹⁰ in D and 4·10⁻¹⁰ in α. The residue formulas match circle integrals to 10⁻¹². `DF[-3,0]` =
  24062.6 against the notebook's 24057.0; the 2·10⁻⁴ difference comes from recomputing `IQ` (iqinterp.mx is binary).
* **Three regimes of the thimble** (for D; ξ = log r):
  * ξ > −2.87: the thimble bends left and traps nothing.
  * −3.8 ≤ ξ ≤ −2.95: the thimble ends on a zero 6 + iγₙ. This is a new Stokes staircase: n = 1, 2, 3, 5, 6, 7, 8, 14 as ξ → −2.87.
  * ξ < −3.85: the thimble escapes to the right and traps the Riemann and dyadic walls.
* **Oscillations.**
  * For r > C_max = e^{−2.76}, D(r) is exactly a convergent series in real powers of 1/r, so α has no oscillations at all there.
    This includes every r > 1 and the whole range compared with the wind tunnel.
  * For r < C_min = e^{−2.92}, the only oscillating terms are the wall poles r^{7+iγₙ} and r^{15/2+2πik/ln2}.
    The dyadic k = 1 term dominates, with period ln 2 in log r. Its amplitude in α is 1.4·10⁻⁶ at log r = −3, 2·10⁻⁹ at −4
    and 8·10⁻¹¹ at −4.5, falling like r^{5.5}. The Riemann terms are about 10⁻¹¹ or smaller.
  * Where every wall pole is trapped, the Stokes residue sum equals this wall sum to 10⁻¹⁰.
* **The large-r oscillations in `CorrelationOscillation.nb` are a cutoff artifact.** `Dv2` integrates `htab` only over
  0.1 < k < 1000, and H(0.1) = 0.037 is not small. The endpoint leaves a term ∝ H(0.1) cos(0.1 r)/r², so xi2 turns negative and
  oscillates for log10 r > 1.4. The exact α_D there is positive and monotone. `htab` agrees with this model's H(κ) to 0.3%.
* **Max Planck (E_Kohler, 11 runs, Re_λ = 413 … 5779).**
  * The tail α_exp < 0.355 is fitted by shifting log(r/η) by s, as in the old notebook.
  * rms 0.014–0.045; s grows like 1.35 log Re_λ (L/η ∝ Re_λ^{3/2} would give 1.5).
  * The Re_λ = 5779 fit reproduces the old log10 shift 5.5.
  * The theory has no inertial plateau (α ≈ 0.7), so only the large-r tail can be compared.
  * The residual wiggles (±0.05) are much larger than anything this model produces.

## Finite box: the small-k cutoff as the tunnel width

The cutoff k > k_min = π/L can stand for the finite width L of the tunnel:
D_L(r) = 2∫_{k_min}^∞ (1 − sin kr/(kr)) H(k) dk = D_∞(r) − ΔD(r).

* D_∞ is the thimble result.
* ΔD = 2∫_0^{k_min} (1 − sin kr/(kr)) H(k) dk.
* H(k) is an entire function of k. Closing the p-contour to the right, only the Γ(−p) poles p = n contribute:
  H(k) = Σ (−1)ⁿ Aₙ kⁿ/n!. This series matches the Mellin line integral to 10⁻¹⁵, and (π/2)H(0) equals the large-r coefficient of f.
* The endpoint k_min makes α_L oscillate about 0 with period 2π/k_min in r. The first dip is near r ≈ L. These oscillations are
  periodic in r, not log-periodic.

Fit to the Max Planck runs (`python/finite_box.py`, `results/mpi_fit_box*.json`, figures 9–11):

| model | free parameters | pooled rms of α |
|---|---|---|
| infinite system, shift s per run | 11 | 0.0302 |
| finite box, one common size L = Λ·r_max for all runs (best Λ ≈ 1.0–1.1) | 12 | 0.0255 |
| finite box, own (s, k_min) per run | 22 | 0.0184 |

* The finite box reproduces the negative dips of α at the largest r.
* The per-run L/η grows with Re_λ and tracks the largest measured separation (L/r_max = 0.3–2.5).
* The highest-Re runs (Re_λ = 3070, 4998, 5779) gain little; for 5779 the fit prefers no cutoff.

### Constant physical width, diffusion-length units, and Re_λ → ∞

The theory's r is the scaling variable ρ = |r₁ − r₂|/ℓ_D, with ℓ_D = √(ν̃ (t + t₀)) and t = z/v̄_z; α depends only on ρ. So the
fitted shift is s = ln(ℓ_D/η), and a physical width W gives k_min = π ℓ_D/W, which differs from run to run.
`python/physical_units.py` gets u′, ν (in two independent ways, agreeing to 1–20%), η and ℓ_D in metres from the files themselves:

* ℓ_D ≈ 1.0–3.6 m, and ℓ_D/L ≈ 7–9 in every run (L is the integral scale from each run's own correlation).
* The implied W = π ℓ_D/k_min is 2.25–2.6 m for Re_λ = 413, 543, 664, 2033 and 2398. A single W = 2.34 m fits the Re_λ ≤ 2398 runs
  with rms 0.023 (0.035 without a box).
* The runs with Re_λ ≥ 3070 show no finite-size dip. Their rms is flat or rising in k_min, so a common W over all runs only reaches
  0.0263.
* Since the theory is for Re_λ → ∞, the index is also extrapolated to infinite Re at fixed r/L (`python/extrapolate_Re.py`,
  figure 12). Using the Re_λ ≥ 1046 runs and α = α_∞ + c Re_λ^{−1}, the infinite-system theory fits α_∞ with χ²/dof = 2.4
  (weighted rms 0.017, s = ln(ℓ_D/L) = 1.96). A box does not improve this: k_min → 0.6.
* The extrapolation uses Re_λ^{−1}; Re_λ^{−1/2} fits worse (χ²/dof 4.5). With only the four highest-Re runs the extrapolation is
  ill-conditioned, because Re_λ^{−1} spans only a factor 2.
